All are in **column 10** (x=120..131), which straddles the x=128 page boundary.

The generate_font_atlas.py code handles this correctly: each pixel is independently mapped to its page via `page_col = x // 128`, so pixels at x=120..127 go to page_col=0 and x=128..131 go to page_col=1. The per-pixel paging logic means no cell data is misplaced.
