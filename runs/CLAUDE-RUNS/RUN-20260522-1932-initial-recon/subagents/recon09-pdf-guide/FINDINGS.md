- **Alleid**: Cooperative attack system (unique to Busin series)
- **Trust**: Party member bond/loyalty mechanic
- **Automata**: Ancient artificial being / party member class
- **Curse**: Negative magic power value on equipment
- **Special Power (SP)**: Item release mechanic
- **Grim Reaper**: Death entity that possesses characters
- **Writhing Evil/Demons (Skedim/Ugomeku)**: Main antagonist creatures
- **Dispel**: Kill/banish undead ability
- **Magic Stones**: Spell items created via synthesis
