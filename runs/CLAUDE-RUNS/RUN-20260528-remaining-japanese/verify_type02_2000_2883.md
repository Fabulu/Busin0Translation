### Key indicators these are NOT dialogue

1. **Identity matrices**: Repeated `00 00 80 3F` (float 1.0) in 4x4 matrix layout at consistent offsets -- standard 3D transformation matrix format
2. **No MSG header**: Real type-02 MSG resources have a recognizable header with message count, offset table, and FFFE-delimited text blocks. None of these have that structure.
3. **File sizes**: Resources like R2099 (263KB) and R2168 (48KB) are far larger than typical text resources
4. **Glyph mapping is coincidental**: The "mapped" characters (e.g., "正", "冒", "「") are just low glyph indices that happen to match small integers in the binary data headers
