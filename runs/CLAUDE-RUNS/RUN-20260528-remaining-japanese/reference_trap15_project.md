# trap15's Busin 0 English Translation Project

## Overview
trap15 has an active Wizardry: Tale of the Forsaken Land (Busin 0) English translation project, announced on RPGCodex in December 2025.

## Target Disc
- **SLPM-65876** (Atlus Best Collection, v2.01)
- This is NOT our target disc (we use SLPM-65378, original release)

## Progress (as of public posts)
- Font renderers mostly wrangled
- Character creation and adventurer's guild screens mostly done
- Bar/tavern text quite far along
- By Jan 2026: finished most event text through tutorial + first tavern request
- By Apr 2026: advanced graphic replacement tools, debug menu functional

## Remaining Work
- Graphics assets replacement
- Atlased texture tooling
- Plans to make patch source available eventually

## Translation Reference
- d1r's 577-page guide (posted RPG Codex, Apr 2021) is the shared translation reference used by both projects

## Relationship to Our Project
- Projects target different disc versions (SLPM-65378 original vs SLPM-65876 Best Collection)
- Complementary efforts, not competing
- Our findings (file formats, offsets, tools) could be shared to benefit both projects
