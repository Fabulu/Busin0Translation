# Scan Results: PACKDATA R1190-R1220 (and surrounding range)

**Date**: 2026-05-28
**Purpose**: Find UI texture atlases with Japanese text in the R1190-R1220 resource range

---

## Summary

**R1190-R1220 contains NO UI text atlases.** This range holds 3D scene/model data (type-02) and environment textures (type-01). The UI texture atlases with Japanese text are located elsewhere in PACKDATA, as documented below.

---

## Resource Classification: R1190-R1229

### R1190 (type-01, 6,144 bytes)
- Small data resource, NOT a texture atlas
- Contains GS register configuration data (128 entries of 0x30-byte blocks)
- Appears to be a lookup/config table, not image data

### R1191 (type-03, 4,096 bytes)
- Small type-03 resource with GIF AD setup
- Contains CLAMP register config (reg 0x08 = 0x05)
- Too small for any meaningful texture

### R1192-R1214 (type-02, varying sizes)
- **All are 3D scene/model data**, NOT textures
- Header pattern: `[0x00000000, sec0_size, 0x00000020, 0x00000000, 0x00000001, sec1_size, sec1_offset, 0x00000000]`
- Section 0 starts with vertex/display-list data (`00 02 00 03 00 3C ...` pattern)
- R1192 (157,696B) contains float 1.0f patterns (transformation matrices)
- R1196-R1213 (75K-170K) contain scene geometry
- R1214 (2,048B) minimal data stub

### R1215-R1229 (type-01, 133,120 or 264,192 bytes)
- **All are environment/scene textures** (building/dungeon imagery)
- Decoded TEX0 registers confirm:

| Resource | Size | Format | Dimensions | Content |
|----------|------|--------|------------|---------|
| R1215 | 264,192 | PSMT8 | 512x512 | Building/ruins scene |
| R1216 | 264,192 | PSMT8 | 512x512 | Building/ruins variant |
| R1217 | 133,120 | PSMT8 | 256x512 | Scene texture |
| R1218 | 133,120 | PSMT8 | 256x512 | Scene texture |
| R1219 | 133,120 | PSMT8 | 256x512 | Scene texture |
| R1220 | 264,192 | PSMT8 | 512x512 | Building/ruins variant |
| R1221-R1229 | mixed | PSMT8 | 512x512 or 256x512 | More scene textures |

- Structure: 0x400 header + GIF chain (DMA + GIF AD regs) + pixel data + 1024-byte CLUT
- All visually confirmed as environment art (stone buildings, ruins) -- NO text content

## Confirmed UI Texture Atlases with Japanese Text

Located outside the R1190-R1220 range:

### R1188 (type-01, 528,384 bytes) -- Name Entry Screen
- **Format**: 1024x1024 PSMT4
- **Content**: Tab labels (katakana/hiragana/alphanumeric/symbol), confirm button, male/female name tabs
- **Japanese text**: Baked bitmap tab/button labels
- **Status**: Identified, deswizzle working, needs English replacement (REMAINING_WORK item M3)
- **Header**: 0xC00 (3,072 bytes), 17 GS A+D register blocks

### R1272 (type-01, 67,584 bytes) -- Main Font Atlas
- **Format**: 256x512 PSMT4
- **Content**: 882-cell grid (21 columns x 42 rows, 12x12px cells)
- **Glyph IDs**: 0-881 (kana, kanji, Latin, symbols)
- **Status**: Already patched with English glyphs in build pipeline

### R2119/R2120/R2122 (type-01, 34,816 bytes each) -- Guild/Shop Button Strips
- **Format**: 512x64 PSMT8
- **Content**: Pre-rendered button graphics for guild/shop menus
- **Structure**: 2,048-byte header + 32,768 pixel bytes + CLUT
- **Japanese text**: Some buttons may have text ("新規登録" etc.)
- **Status**: Previously rendered (build/textures_to_edit/R2122_guild_buttons_*.png)

### R2118/R2121 (type-01, 264,192 bytes each) -- Guild Background/UI
- **Format**: 512x512 PSMT8
- **Content**: Large UI background textures
- **Status**: Previously rendered (build/textures_to_edit/R2118_*.png, R2121_*.png)

## Key Finding: Where Japanese Text Actually Lives

1. **R1188 (name entry atlas)**: Baked Japanese tab labels -- needs pixel-level editing
2. **R2119/R2122 (guild buttons)**: Pre-rendered button text -- may need editing
3. **EXE menu structs**: Japanese glyph IDs at 0x3C3000-0x3C5300 -- need remapping to English glyphs
4. **Font-rendered text**: Dynamically rendered through R1272 glyph system -- already handled by font atlas replacement + glyph table
5. **Type-02 MSG resources**: Dialogue text using glyph encoding -- handled by translation pipeline

**R1190-R1220 is entirely 3D scene data and environment textures. No UI text translation work needed in this range.**
