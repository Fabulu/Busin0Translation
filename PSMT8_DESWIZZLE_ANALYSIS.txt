================================================================================
ALGORITHM COMPLEXITY
================================================================================

The PSMT8 swizzle algorithm is MORE COMPLEX than simple bit permutation due to:

1. Block-based organization (16x16 pixel blocks with specific ordering)
2. Within-block pixel arrangements that follow a pattern (likely Z-order/Morton code)
3. Different treatment of X and Y coordinates
4. Bit manipulation/XOR operations on coordinates
5. Page-level swizzling (64x32 pixel pages subdivided into 4x2 block grid)

Standard PS2 PSMT8 swizzle formula involves:
- Dividing texture into 64x32 pixel pages
- Each page contains 4x2 grid of 16x16 pixel blocks
- Blocks are numbered left-to-right, top-to-bottom
- Within each block, pixels stored with Z-order (Morton code) or custom swizzle
